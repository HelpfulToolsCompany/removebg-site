Technical details

        
Plain engineering facts—no hidden caveats.

        

          

            
Exact API Shape

            
Supports image_file, image_url, image_file_b64, size, format, bg_color, and crop. Returns raw image bytes and remove.bg error JSON.

          

          

            
Zero Image Storage

            
Every image is decoded, segmented with ISNet (isnet-general-use), and returned strictly in memory. Nothing is written to disk or logged.

          

          

            
Product Photo Ready

            
Clean cutouts on e-commerce products, studio shots, and general objects. Outputs PNG, WebP, or JPEG.

          

          

            
Cold-Start Note

            
Scales to zero when idle; the first call after idle can take ~10s while the container boots. Batch jobs are unaffected.
